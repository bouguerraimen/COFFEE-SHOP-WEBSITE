# ☕ Haven Coffee Shop

A simple website for **Haven World**, a cozy bakery and coffee house, made with HTML and CSS.

🔗 **Visit the website:** [bouguerraimen.github.io/COFFEE-SHOP-WEBSITE](https://bouguerraimen.github.io/COFFEE-SHOP-WEBSITE/)

---

## ✨ Features

- **Home section** with a welcome message and two buttons ("Let's Eat" and "Book a Table")
- **Popular drinks** with photos, descriptions and prices (Cappuccino, Iced Latte, Mocha, Espresso)
- **Table booking form** (first name, last name, date, number of guests)
- **About us** section telling the story of the shop
- **Footer** with quick links, opening hours and contact details
- **Navigation menu** linking to each section (Home, Menu, About Us, Book)

## 🛠️ Built with

- HTML5
- CSS3
- Hosted on [GitHub Pages](https://pages.github.com/)

## 🚀 Getting started

No installation or build step is needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/bouguerraimen/COFFEE-SHOP-WEBSITE.git
   ```
2. Open the project folder:
   ```bash
   cd COFFEE-SHOP-WEBSITE
   ```
3. Open `index.html` in your browser.
